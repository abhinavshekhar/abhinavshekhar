## `whoami`

I build **AI-powered systems and full-stack products** around a simple engineering question: *can a messy real-world problem be turned into a system that is faster, clearer, and more useful?*

That has led me from **medical imaging assistants** to **hackathon prototypes**, mobile apps, data tooling, and portfolio builds — all while studying **AI & Robotics** at VIT Chennai.

- 🎓 **Education:** B.Tech CSE (AI & Robotics), VIT Chennai — First Year
- 🏥 **SIH Hackathon:** Built a radiology AI assistant for chest X-ray, CT, MRI & ultrasound analysis
- ⚙️ **Current obsession:** agentic AI, embodied intelligence, backend architecture & shipping things that actually work
- 🤝 **Open to:** ambitious builds, hackathons, AI/ML engineering & full-stack collaboration

### 🏥 [Radiology AI](https://github.com/abhinavshekhar/radiology-ai)
**SIH hackathon — AI assistant for medical imaging analysis.**

A full-stack radiology workflow combining **FastAPI, React and vision models** to analyze chest X-rays, CT scans, MRI and ultrasound images — built for real clinical use cases under hackathon constraints.

### ⚡ [Prompt × Nexus](https://github.com/abhinavshekhar/promptxnexus)
**Hackathon product built at PromptWar × Nexus.**

Rapid end-to-end prototyping — from idea to deployed demo — with a focus on clean UI and fast iteration under time pressure.

### 📱 [MTC Companion+](https://github.com/abhinavshekhar/mtc-companion-plus)
**A modern companion app with polished web UX.**

Built with **JavaScript and React patterns**, focused on usability, responsive design and real-world interaction flows.

### 📊 [S-Data](https://github.com/abhinavshekhar/S-Data)
**Data tooling and visualization project.**

TypeScript-powered tooling for working with structured data — exploring how raw information becomes something actionable.

### 🌐 [My Website](https://github.com/abhinavshekhar/my-website)

A hand-built site documenting my journey from Samastipur to VIT Chennai, hackathon builds, and the skills I'm actively developing.

### 📲 [Farmer Record App](https://github.com/abhinavshekhar/Farmer-record-app-internship-project)
